## SystemCare

أداة SystemCare هي سكريبت Bash متطور لأنظمة لينكس، توفر صيانة شاملة ومؤتمتة تتضمن: النسخ الاحتياطي المضغوط، تقارير حالة النظام، تحليل سجلات الدخول الأمنية، نقل الملفات بشبكة مشفرة عبر OpenSSL، وإدارة أجهزة ويندوز، مع توثيق دقيق لكافة العمليات في سجل خاص.

## 🚀 المميزات الرئيسية
- النسخ الاحتياطي المضغوط مع إدارة وفلترة النسخ القديمة.
- تقارير حالة النظام الشاملة (القرص، الذاكرة، والعمليات).
- تحليل سجلات المصادقة (`auth.log`) لرصد الدخول الفاشل.
- الإرسال الشبكي المشفر للملفات عبر OpenSSL.
- سجل عمليات زمني دقيق.
